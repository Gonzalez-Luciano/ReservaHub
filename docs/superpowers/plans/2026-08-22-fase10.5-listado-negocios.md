# Fase 10.5 — Listado público de negocios: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que un cliente pueda descubrir qué negocios existen — un listado web público en `GET /negocios`, su equivalente REST en `GET /api/businesses` para el cliente con token, un link desde la portada y datos de demo con más de un negocio.

**Architecture:** Todo es aditivo. Dos rutas nuevas que van **fuera** de los grupos con prefijo de slug (`negocios/{business:slug}` en web, `businesses/{business:slug}` en API), porque esos grupos llevan `BindPublicBusiness`, que necesita un slug. El filtro es `is_active = true` y nada más. `App\Models\Business` no aplica `BusinessScope` (es la raíz del tenant), así que las consultas corren sin contexto de negocio. Ninguna tarea modifica un flujo existente salvo el link de `Home.jsx`, la idempotencia del `DemoSeeder` y documentación.

**Tech Stack:** Laravel 12 + Inertia (React 19, Tailwind 4), PostgreSQL, Sanctum, PHPUnit, Pint. Todo corre en Docker (Laravel Sail) — nunca `php artisan serve` ni `vendor/bin/sail` (falla en Git Bash).

**Spec:** `docs/superpowers/specs/2026-08-22-fase10.5-listado-negocios-design.md`

## Global Constraints

- **Todo comando corre dentro del contenedor**: `docker compose exec laravel.test <cmd>`. `vendor/bin/sail` está roto en Git Bash (`Unsupported operating system [MINGW64_NT-...]`).
- **Package manager: pnpm**, nunca npm. No existe `package-lock.json`.
- **Idioma**: todo texto de UI, mensajes de validación y comentarios de dominio en español. Los mensajes de commit, en inglés (convención del repo).
- **Filtro único del listado**: `is_active = true`. Nada de filtrar por servicios activos, buscar, paginar, ordenar por otra cosa que `name`, ni categorías.
- **Sin trabajo visual**: mismo mínimo de Tailwind que `resources/js/Pages/Public/Business/Show.jsx`. El diseño es Fase 11.
- **Envelope de la API**: toda respuesta es exactamente `{success, data, message, errors}` vía `App\Support\ApiResponse`. El listado va **sin paginar** (precedente: `Api\ServiceController::index`).
- **Formato**: `vendor/bin/pint --test` tiene que pasar antes de cada commit de código PHP.
- **Fuera de alcance de este repo**: cualquier trabajo de servidor de producción, Cloudflare o despliegue (ver CLAUDE.md, "Responsibility boundary").

- [ ] **Step 3: Reescribir el seeder con guard por negocio**

Reemplazar el contenido de `database/seeders/DemoSeeder.php` por:

```php
<?php

namespace Database\Seeders;

use App\Enums\DayOfWeek;
use App\Enums\Role;
use App\Models\Business;
use App\Models\Schedule;
use App\Models\Service;
use App\Models\User;
use Illuminate\Database\Seeder;

class DemoSeeder extends Seeder
{
    public function run(): void
    {
        $this->seedBusiness(
            slug: 'peluqueria-demo',
            name: 'Peluquería Demo',
            ownerEmail: 'owner@reservahub.test',
            employees: [
                ['name' => 'Ana Empleada', 'email' => 'ana@reservahub.test'],
                ['name' => 'Beto Empleado', 'email' => 'beto@reservahub.test'],
            ],
            services: [
                ['name' => 'Corte de cabello', 'duration_minutes' => 30, 'buffer_minutes' => 5, 'price' => 3500],
                ['name' => 'Coloración', 'duration_minutes' => 90, 'buffer_minutes' => 15, 'price' => 12000],
                ['name' => 'Manicura', 'duration_minutes' => 45, 'buffer_minutes' => 5, 'price' => 4000],
                ['name' => 'Masaje', 'duration_minutes' => 60, 'buffer_minutes' => 10, 'price' => 8000],
                ['name' => 'Depilación', 'duration_minutes' => 30, 'buffer_minutes' => 10, 'price' => 5000],
            ],
        );

        $this->seedBusiness(
            slug: 'estudio-demo',
            name: 'Estudio Demo',
            ownerEmail: 'owner2@reservahub.test',
            employees: [
                ['name' => 'Carla Empleada', 'email' => 'carla@reservahub.test'],
            ],
            services: [
                ['name' => 'Clase de guitarra', 'duration_minutes' => 60, 'buffer_minutes' => 10, 'price' => 6000],
                ['name' => 'Grabación de demo', 'duration_minutes' => 120, 'buffer_minutes' => 30, 'price' => 20000],
            ],
        );
    }

    /**
     * @param  array<int, array{name: string, email: string}>  $employees
     * @param  array<int, array{name: string, duration_minutes: int, buffer_minutes: int, price: int}>  $services
     */
    private function seedBusiness(string $slug, string $name, string $ownerEmail, array $employees, array $services): void
    {
        // Idempotencia por negocio: un guard global impediría sembrar un negocio
        // nuevo en una instalación donde el primero ya existe.
        if (Business::where('slug', $slug)->exists()) {
            return;
        }

        $business = Business::create([
            'name' => $name,
            'slug' => $slug,
            'timezone' => 'America/Argentina/Buenos_Aires',
            'currency' => 'ARS',
            'cancellation_hours' => 24,
            'is_active' => true,
        ]);

        User::factory()->create([
            'name' => $name.' Owner',
            'email' => $ownerEmail,
            'password' => 'password',
            'role' => Role::Owner,
            'business_id' => $business->id,
        ]);

        $employeeModels = User::factory()
            ->count(count($employees))
            ->sequence(...$employees)
            ->create([
                'password' => 'password',
                'role' => Role::Employee,
                'business_id' => $business->id,
            ]);

        $serviceModels = Service::factory()
            ->for($business)
            ->count(count($services))
            ->sequence(...$services)
            ->create();

        $weekdays = [DayOfWeek::Monday, DayOfWeek::Tuesday, DayOfWeek::Wednesday, DayOfWeek::Thursday, DayOfWeek::Friday];

        foreach ($employeeModels as $employee) {
            foreach ($weekdays as $day) {
                Schedule::factory()->for($business)->create([
                    'employee_id' => $employee->id,
                    'day_of_week' => $day,
                    'start_time' => '09:00',
                    'end_time' => '18:00',
                ]);
            }

            $employee->services()->sync($serviceModels->pluck('id'));
        }
    }
}
```
